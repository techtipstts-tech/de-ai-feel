# 台灣繁中編輯判斷卡

這份參考檔處理的是「台灣讀者會不會卡住」，不是判定哪個地區的中文比較正確。同一個詞在產品介面、工程文件、社群貼文與逐字引言裡，可能有不同答案。

## 判斷順序

看到疑似中國用語時，依序確認：

1. **它是名稱嗎？** 品牌、平台、功能、書名與活動名稱照官方寫法。
2. **它是逐字引言嗎？** 引言保留原話，需要時在引言外補說明。
3. **讀者是誰？** 面向台灣一般讀者時從嚴；跨地區團隊內部文件可保留共同術語。
4. **它只是詞不同，還是整句思路不同？** 商業黑話通常要整句改，單換同義詞仍然空。
5. **替換後意思有沒有變窄？** 例如「註銷」可能指刪除帳號，也可能只是登出，必須先看功能。

## 數位產品與介面

| 原稿常見寫法 | 台灣對外文字建議 | 判斷提醒 |
| --- | --- | --- |
| 軟件／硬件 | 軟體／硬體 | 產品名稱除外 |
| 網絡 | 網路 | 「社交網絡」可依內容改「社群網絡」 |
| 數據庫 | 資料庫 | 工程程式碼與欄位名不改 |
| 服務器 | 伺服器 | 引言照原文 |
| 屏幕 | 螢幕 | 電影「銀幕」是另一個詞 |
| 鼠標 | 滑鼠 | 產品正式名稱除外 |
| 打印 | 列印 | 實體印刷也可寫「印出來」 |
| 內存 | 記憶體 | 不要和儲存空間混用 |
| 移動端 | 手機版、行動裝置 | 依實際範圍選一個 |
| 默認 | 預設 | 若指默認同意，整句需重寫 |
| 支持某功能 | 支援某功能 | 「支持某主張」仍可用支持 |
| 兼容 | 相容 | 技術文件可補版本條件 |

## 工作與商業黑話

這一組通常不適合逐詞替換。先找出「誰要做什麼，完成後看哪個結果」。

| 原稿詞 | 改寫時追問 | 可採用的方向 |
| --- | --- | --- |
| 賦能 | 誰因此多了什麼能力？ | 提供權限、教會操作、縮短處理時間 |
| 抓手 | 真正要先動哪一件事？ | 切入點、第一步、負責項目 |
| 閉環 | 哪兩段流程原本沒有接起來？ | 補上回報、追蹤、驗收或回購步驟 |
| 落地 | 要產出什麼可驗收的東西？ | 上線、交付、試跑、實作 |
| 打法 | 實際採用哪些動作？ | 做法、投放組合、銷售流程 |
| 拉通 | 哪些人或系統要同步？ | 串接資料、統一規格、召集確認 |
| 對齊 | 要一致的是目標、數字還是時程？ | 確認目標、核對版本、統一截止日 |
| 沉澱 | 最後會留下什麼？ | 整理成文件、建立範本、保存紀錄 |
| 顆粒度 | 哪個部分需要更細？ | 補欄位、拆步驟、增加條件 |
| 復盤 | 這次要回看什麼？ | 回顧結果、檢討流程、整理下次做法 |

例：

- 原稿：下週會拉通各部門，把新流程落地。
- 資訊足夠時：下週由營運、客服和工程一起確認欄位，月底前讓新表單上線。
- 資訊不足時：下週會召集相關部門確認新流程。`〔待補：參與部門、完成時間、交付項目〕`

## 日常與敘述語氣

| 原稿常見寫法 | 台灣常用方向 |
| --- | --- |
| 質量 | 品質；若指數量，直接寫數量 |
| 水平 | 水準、程度 |
| 立馬 | 馬上、立刻 |
| 挺好的 | 蠻好的、滿不錯的 |
| 靠譜 | 可靠、靠得住 |
| 給力 | 很有力、很猛、很到位 |
| 接地氣 | 貼近日常、講得很生活化 |
| 小夥伴 | 大家、夥伴、朋友 |
| 早上好 | 早安 |
| 晚上好 | 晚安；若是開場可寫「大家晚安」 |
| 溝通一下 | 跟你確認、一起討論 |
| 同步一下 | 更新進度、核對資訊 |

台灣社群已使用的跨區詞不必見一個殺一個。像「內卷」「躺平」常帶有特定網路語氣，保留與否看作者平常用法和讀者是否理解。

## 句法校正

單字都換完，整句仍可能不自然。優先處理這幾種結構：

### 名詞堆疊

- 原稿：針對會員體驗進行持續性的優化。
- 建議：我們會繼續調整會員流程。
- 更好：若原稿有資料，直接說改哪一步、解決哪個問題。

### 主詞消失

- 原稿：經溝通後將進行方案調整。
- 建議：確認真正主詞後，寫成「營運團隊討論後，會調整方案」。

### 長修飾語塞在名詞前

- 原稿：這是一套可以協助第一次經營社群的人快速建立內容節奏的方法。
- 建議：第一次經營社群，可以用這套方法安排每週的內容節奏。

### 「給到」與「安排上」

- 「給到完整支持」要改成具體提供什麼。
- 「優惠安排上了」可改「優惠已經開放」，再補期限。

## 標點與版面

- 中文敘述使用全形逗號、句號、冒號、分號、問號與驚嘆號。
- 數字、網址、程式碼與英文縮寫維持半形。
- 第一層引號用「」，引號裡再引用用『』。
- 並列詞用頓號「、」；完整子句用逗號或分號。
- 刪節號使用「⋯⋯」，不要用三個半形句點。
- 社群平台若不支援 Markdown，發佈前移除井號標題、粗體星號與反引號。
- 中英文間是否留空格依品牌規範統一；同一份稿件不要忽有忽無。

## 量詞速查

- 一支手機、一台電腦、一則貼文、一篇文章、一封信、一段影片。
- 影片也可依內容寫「一支廣告」「一集節目」「一部電影」，不要所有影音都套同一個量詞。
- 軟體版本、方案、人次、下載次數等量詞，以產品實際計算方式為準。
